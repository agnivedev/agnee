# Agnee brand assets

## Files

- `agnee-logo-primary.svg` — primary horizontal lockup with “by beweix”.
- `agnee-logo-compact.svg` — compact header/navigation lockup.
- `agnee-mark.svg` — standalone app icon and avatar symbol.
- `agnee-app-icon.svg` — ready-to-use app tile on a dark brand surface.
- `agnee-mark-mono-dark.svg` — one-color mark for light backgrounds.
- `agnee-mark-mono-light.svg` — one-color mark for dark backgrounds.
- `agnee-by-beweix-logo-v1.png` — original raster concept.

## Usage

- Keep clear space around the logo equal to the inner counter of the mark.
- Do not place the gradient mark on busy imagery without a quiet backing surface.
- Use the compact lockup below 720 px and the mark alone below 36 px.
- Use the monochrome variants for printing, embossing, and low-contrast surfaces.
- The primary green range is `#C7FF35` → `#42DF58` → `#00A96B`.
- Endorsement colors are `#315047` and `#173A30`.

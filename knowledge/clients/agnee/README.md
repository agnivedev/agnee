# Knowledge Agnee

Knowledge terpisah untuk chatbot landing page, demo, dan penjualan platform
Agnee. Isinya membahas customer desk WhatsApp, FAQ automation, funneling, MCP,
integrasi, onboarding, keamanan, dan batasan MVP.

Aktifkan hanya untuk channel Agnee dengan `KNOWLEDGE_CLIENT=agnee`. Jangan pakai
knowledge ini pada nomor WhatsApp bZone karena produk, harga, dan funnel berbeda.

Status masih `draft/internal`: harga final, SLA, timeline implementasi, dan
fitur enterprise tidak boleh dijanjikan sebelum dikonfirmasi.
